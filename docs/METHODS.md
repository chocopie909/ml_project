# Экспериментальный протокол

## Данные и разделение

Два реальных небольших набора встроены в scikit-learn. Сеть нужна только для установки зависимостей. Все ноутбуки используют одни и те же детерминированные индексы: seed 42, train/validation/test примерно 60/20/20. В классификации используется стратификация. Индексы не пересекаются; это проверяется тестом. Размеры и хеши данных записаны в `reports/run.json`.

StandardScaler обучается только на train. В SVM с калибровкой весь pipeline, включая scaler, обучается отдельно внутри train-folds. Target стандартизируется только для оптимизаторов; все регрессионные метрики пересчитываются в исходные единицы.

## Выбор моделей

- Ridge/Lasso: alpha 0.01, 0.1, 1, 10, 100; минимум validation RMSE.
- GD, SGD, Momentum, Adam: learning rate 0.001, 0.01, 0.03; 700 обновлений; минимум validation RMSE. SGD использует один minibatch из 32 объектов за обновление. Сравнение не выравнивает время или количество просмотренных объектов.
- LogisticRegression и SVM: C 0.1, 1, 10; максимум validation ROC-AUC. SVM: sigmoid-калибровка, cv=3 на train.
- CART: max_depth 2, 3, 4, 6; min_samples_leaf 3, 8; максимум validation ROC-AUC.
- Boosting: learning_rate 0.05, 0.1, 0.3; max_depth 1, 2; максимум validation ROC-AUC. Собственная модель до 200 деревьев, patience=15 по validation log loss. Sklearn-модель фиксированно использует 200 деревьев.

Модели не переобучаются на train+validation после выбора; в таблицах test оценивает те же модели, которые выбирались по validation. Параметры по test не меняются. Дополнительное исследование потерь/регуляризации оценивается только по validation.

## Метрики

Регрессия: RMSE, MAE, R². Классификация: Accuracy, Precision, Recall, F1, ROC-AUC, Brier score, log loss. Positive class = malignant. Классификация использует порог 0.5, который не подбирается по test.

ROC-AUC — ранжирование; Brier и log loss оценивают вероятности. Дерево может выдавать вероятности 0/1, поэтому редкие ошибки приводят к большой log loss. Калибровочный график на небольшом test — описательный, не основание для дополнительной настройки.

## Ограничения

Один seed и небольшие данные, без доверительных интервалов. Высокая ROC-AUC на WDBC не доказывает качество на новых клинических данных. Нет медицинской валидации. Нет claims про production, универсальную победу модели или все задания оригинального курса. Учебные реализации поддерживают ограниченный набор возможностей; неподдерживаемые GOSS/квантование/категориальные деревья не заявляются.
