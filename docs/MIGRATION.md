# Что изменилось относительно первой сборки

Первая версия была организацией чужих материалов: исходные ноутбуки не проходили полный запуск. Эта версия — отдельная переработанная программа из пяти тем, которая проверяется командой `python scripts/verify.py`.

| Раньше | Теперь |
|---|---|
| Отсутствующие train.csv, autos.csv, x.npz, y.npy | Два реальных набора внутри scikit-learn |
| Путь /content/train.csv | Автопоиск корня проекта из ноутбука |
| Ошибочные/неполные ветки потерь | Четыре потери с проверкой градиента конечными разностями |
| Изменение весов при L2 | Копия весов, intercept исключён из штрафа |
| Неоднозначная обработка min_samples_leaf | Фильтрация недопустимых порогов до выбора лучшего |
| Двойное преобразование меток в бустинге | Единый контракт y ∈ {0,1} |
| Неиспользуемый learning_rate | Одинаковое shrinkage при fit и predict |
| Только проверка хешей и синтаксиса | Тесты вычислений + все эксперименты + чистые kernel-запуски всех ноутбуков |

Исходные домашние задания с Taxi, Autos, Adult, Bank Marketing и прочими данными не восстановлены один в один. Темы сохранены, объём честно ограничен рабочими модулями. Старые исходники доступны по ссылке в ATTRIBUTION; они не импортируются.

## Обновление GitHub

Новая версия должна **заменить** первую сборку, а не смешаться с ней. Если обновляете существующий репозиторий, удалите старые пять подпапок notebooks/01-linear-regression ... notebooks/05-boosting, старые scripts/benchmark.py и check_project.py, старые docs/source-manifest.json, notebook-audit.json и STATUS.md. Удалите старые benchmark.csv/run.json перед заменой reports. README, ATTRIBUTION, requirements и обзорный ноутбук заменяются новыми.

Удобнее использовать GitHub Desktop для замены содержимого целиком, сохраняя папку .git. Не нужно удалять сам репозиторий или переписывать его историю. Веб-загрузка также возможна, но папки должны сохраниться.

Если проще создать отдельный репозиторий для рабочей версии, прежний можно оставить как архив материалов. Автоматическое удаление/перезапись существующего GitHub в этой поставке не выполняется.
