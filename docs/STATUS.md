# Статус исходных ноутбуков

## Недостающие данные

- Регрессия: `/content/train.csv` — данные поездок такси; файл не включён. Нужно предоставить набор и исправить путь.
- Градиентный спуск: `autos.csv` — объявления автомобилей; файл не включён.
- Классификация: `adult.data` включён; остальные части используют KaggleHub и UCI, требуют сети и дополнительных данных.
- Деревья: `students.csv`, `agaricus-lepiota.data`, `tic-tac-toe-endgame.csv` отсутствуют; California Housing загружается через scikit-learn.
- Бустинг: `x.npz` и связанные метки не включены; изображение `bonuska.jpg` также отсутствует.

Точный список локальных обращений: `notebook-audit.json`. Файлы не подменялись случайными датасетами.

## Замечания по коду при чтении

- `descents.py`: ветки MAE/Huber в `calc_loss` сравнивают `self` с Enum вместо `self.loss_function`; в MAE есть `selfpredict`. Градиент MAE полного спуска возвращает скаляр; Huber обращается к неинициализированному `trshold`. Регуляризация изменяет веса через ссылку `l2_gradient = self.w`.
- `boosting.py`: метки преобразуются в `fit` и повторно в `partial_fit`; `learning_rate` не применяется к накоплению предсказаний; объявленные GOSS/RSM/квантизация не подключены к основному шагу обучения.

Это статические наблюдения, не полный code review. Исходный код сохранён для изучения. Его корректность и полная воспроизводимость не заявляются.

## Проверки сборки

`scripts/check_project.py` проверяет JSON-структуру ноутбуков, отсутствие сохранённых выводов и соответствие хешей manifest. Benchmark запускается отдельно; его результаты и версии зависимостей сохраняются в `reports`.
